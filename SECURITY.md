# Security policy

## Supported versions

Security and save-safety fixes are provided for the latest published release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for a vulnerability that could corrupt saves, execute
unexpected code, or expose local data.

Include the affected version, game distribution, UE4SS version, reproduction
steps, and the smallest relevant log excerpt. Do not include save files or
personal paths unless specifically requested through the private report.
